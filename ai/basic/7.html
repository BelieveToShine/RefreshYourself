Zero-shot, few-shot, chain-of-thought — how much do you have to spell out before the model gets it right?

"What's the difference between zero-shot, few-shot, and chain-of-thought prompting?"

Why it matters ▾
  • Almost always the follow-up right after "what is prompting" — it checks whether you know the actual technique names, not just "write a good prompt."
  • Explains a real, everyday fix: pasting 2-3 example input/output pairs into a prompt is often the fastest way to correct a model returning the wrong format, with no retraining involved.
  • Chain-of-thought is the standard explanation for why asking a model to "think step by step" measurably helps on math and logic questions.
🔥 Easy interview recall

Zero-shot → no examples, just the ask

Few-shot → a few examples IN the prompt

Chain-of-thought → ask it to reason step-by-step first

Think: every rung adds more into the prompt itself — examples, then reasoning — the model's weights never change.

🧠 Visual Mental Model — understand it in 5 seconds
⚠️ Common Trap

Few-shot examples don't retrain or fine-tune the model. Those example pairs only exist inside that one prompt's context — start a new conversation without them, and the model has no memory of the pattern; you'd have to paste them in again.

🔄 Likely Follow-up

"How do you push accuracy even further than a single chain-of-thought pass?" Self-consistency — sample multiple independent chain-of-thought reasoning paths for the same question and take the majority (or most consistent) final answer; it trades more inference calls for higher accuracy on hard reasoning tasks.

🎯 Say this in the interview — the exact lines to land

"Zero-shot just asks the model to do the task with no examples. Few-shot adds a handful of example input/output pairs directly in the prompt so it can copy the pattern and format. Chain-of-thought asks the model to reason step-by-step before answering, which measurably helps on multi-step math and logic problems."

  • Zero-shot → no examples — the cheapest option, try it first.
  • Few-shot → add a few example pairs when you need a specific output format.
  • Chain-of-thought → ask for step-by-step reasoning on multi-step math or logic questions.
  • Self-consistency → sample several reasoning paths, keep the majority answer, for even higher accuracy.
📖 Explanation ▾

All three sit on the same ladder, and none of them touch the model's weights — every rung only adds more text to the prompt itself. Zero-shot is a plain instruction or question with no examples attached. Few-shot pastes a handful of example input/output pairs into that same prompt, which measurably improves accuracy and format-following just from seeing the pattern once. Chain-of-thought adds a request to reason step-by-step (or show the reasoning) before answering — this measurably helps multi-step tasks like math, logic, and multi-hop questions, compared to asking for the answer directly.

Self-consistency pushes chain-of-thought one step further: instead of trusting one reasoning attempt, sample several independent chain-of-thought answers to the same question and keep whichever final answer comes up most often. It costs more inference calls — several full generations instead of one — but it's a real accuracy lever on genuinely hard reasoning problems, not a theoretical one.

Prompt 
Q: A store had 23 apples. They sold 8 and got a new
delivery of 15. How many apples are there now?
A: Let's think step by step.

Adding "let's think step by step" pushes the model to show its reasoning before the final number, which measurably improves accuracy on multi-step problems like this one.

🌍 Real-world example ▾

Zero-shot is asking a new hire to write a report with no template. Few-shot is handing them two finished reports to copy the structure from. Chain-of-thought is asking them to explain their reasoning out loud before giving the final number, so they catch their own mistakes along the way.
