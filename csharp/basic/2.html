Boxing & Unboxing — turning a value into an object, and back

Why it matters ▾
  • Explains a performance hit hiding inside completely "normal-looking" code.
  • Tells you why List<int> beats ArrayList for value types.
  • Comes up the moment generics or collection history gets mentioned.
📖 Explanation ▾

Boxing happens the moment a value type needs to be treated as an object — pass an int where an object parameter is expected, or drop it into a non-generic ArrayList, and C# quietly allocates a new box on the heap and copies the value in. You didn't ask for an allocation — it happened anyway.

Unboxing is the trip back: cast that boxed object back to its exact original value type. C# checks the type first — get it wrong (unbox an int as a long, say) and it throws InvalidCastException right there, no silent conversion.

Modern generic collections (List<int>) were built specifically to avoid this — a generic list of int stores real ints, no boxing at all.

💻 See the code ▾ 
int n = 5;
object boxed = n;            // boxing — new heap allocation
int n2 = (int)boxed;         // unboxing — checked cast

ArrayList list = new ArrayList();
list.Add(42);                 // boxes 42 silently

List<int> nums = new List<int>();
nums.Add(42);                  // no boxing — stores a real int
🌍 Real-world example ▾

Coin in an envelope. Boxing is sealing a coin inside an envelope so it can go in the mail slot marked "objects only" — now it's an envelope, not a coin. Unboxing is tearing that envelope back open to get the coin out — and you'd better be expecting a coin, not a button, or you're in for a surprise.

🎯 Say this in the interview — the exact lines to land

  • Boxing wraps a value type in a heap object. Unboxing unwraps it back.
  • Every box is a new heap allocation — do it in a loop, feel it in GC pressure.
  • Unboxing to the wrong type throws InvalidCastException — checked, not silent.
  • ArrayList, object params → box silentlyList<int> and other generics → no boxing
  • It's invisible in the code — no cast, no keyword marks a boxing operation happening.
