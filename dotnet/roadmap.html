🧱 .NET / ASP.NET Core — interview question taxonomy

Rescopes the site's old, never-written ".NET Framework" slot — this track is about modern, cross-platform .NET + ASP.NET Core, a different technology from the legacy Windows-only Framework. MVC lives inside this track as its own group below (per the user's decision), not as a separate track or folder. Phase 1 only — no tier or priority assigned yet. Full detail in docs/superpowers/specs/dotnet/question-taxonomy.md.

1. .NET Fundamentals 4 concepts ▾
  • .NET vs. .NET Framework
  • CLR, BCL & Managed Code
  • SDK vs. Runtime, .csproj & NuGet
  • What Happens When a .NET App Starts — Kestrel, the Generic Host
2. Dependency Injection 2 concepts ▾
  • The Built-in DI Container
  • Service Lifetimes — Singleton vs. Scoped vs. Transient
3. ASP.NET Core Request Pipeline 5 concepts ▾
  • Middleware — Use/Run/Map, ordering
  • Authentication vs. Authorization (as pipeline stages)
  • Routing — endpoint routing
  • Model Binding & Validation
  • Filters, Global Exception Handling, CORS, HTTPS, Logging
4. MVC 6 concepts ▾
  • What Is MVC — Model/View/Controller, Controller vs. ViewModel
  • ViewBag vs. ViewData vs. TempData
  • Razor & Routing
  • MVC-Specific Filters — action/authorization/exception, execution order
  • Views, Layouts & Organization — partials, Areas
  • Model Binding Internals, and MVC vs. Web API vs. Razor Pages
5. Configuration & Options 1 concept ▾
  • Configuration Sources — appsettings, env vars, IOptions<T>
6. Authentication & Authorization 2 concepts ▾
  • Authentication Schemes — cookie vs. token-based
  • Authorization Policies & Claims
7. Error Handling 1 concept ▾
  • Global Exception Handling — dev exception page vs. production
8. Hosting 2 concepts ▾
  • Kestrel & Reverse Proxies
  • The Generic Host & Application Lifetime
