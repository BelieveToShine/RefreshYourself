## 2. Site shell (`assets/`, page head) — bugs and a11y

P1
1. `site.js` search results inject `item.title` unescaped (`innerHTML`): ~139 titles with `<`/`&` (e.g. `List<T>`) lose text. Hoist `esc()`, escape in `highlight()`.
2. Back-tagging appends `?bfrom=…` after an existing `#hash` (breaks anchor + Back).
3. Back-tagging handler rewrites `href` permanently and also fires on Ctrl/Cmd/Shift-click.
4. `iconFor()` lacks AWS, Angular, Python, JavaScript, HTML & CSS (~227 results show 📄).
5. The "/" shortcut badge is shown on every page but no handler exists.
6. Search has no combobox ARIA (`role=combobox`, `aria-expanded`, `aria-activedescendant`, ids on options); `outline:none` on the input.
7. Blur clears results after 150 ms; refocus shows nothing until typing; Enter can act on stale items.

P2: copy button has no fallback without `navigator.clipboard` (http/file://) and no `.catch`; tier-nav uses `:focus` not `:focus-visible`, no `aria-current="page"`, aside not `<nav>`; link underline only on `:hover`; no `prefers-reduced-motion` handling (`scroll-behavior:smooth` unconditional); `bopen` index not NaN-guarded; no `<meta name="description">`, favicon or OG tags on any page; fonts via render-blocking `@import`; ~35 lines of header boilerplate (inline brand SVG, duplicate `<defs>` ids) copied into ~700 pages, no skip-link; decorative `.gicon`/`.gkey` not `aria-hidden`.
