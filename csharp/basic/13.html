C# · Basic · Normal

Two tiny operators, two different questions

Why it matters ▾
  • These two symbols show up in almost every real codebase — worth being fluent in both.
  • Mixing them up (asking "is this true?" vs. "is this null?") is a common beginner slip.
  • Both are just shorter, easier-to-read forms of an ordinary if.
🔥 Easy interview recall

"Ternary ?: selects a value based on a condition, while null-coalescing ?? provides a fallback when the left side is null."

Think: ?: asks true/false · ?? asks null-or-not

🧠 Visual Mental Model — understand it in 5 seconds
⚠️ Common Trap

?? only checks for null — not false, 0, or empty string. int? x = 0; x ?? 5 gives 0, not 5, because 0 isn't null.

🎯 Say this in the interview — the exact lines to land

"?: picks a value from a true/false condition — a compact if/else. ?? picks a fallback only when the left side is null — nothing to do with true/false."

  • ??= assigns only if currently null.
📖 Explanation ▾

The ternary operator (?:) is a compact if/else that returns a value: condition ? whenTrue : whenFalse. It only cares whether the condition is true or false — nothing to do with null.

The null-coalescing operator (??) checks one specific thing: is the left-hand side null? If it isn't, you get the left side back unchanged. If it is, you get the right side instead. There's also ??=, which assigns the right side only if the variable is currently null.

They solve different problems and are easy to reach for interchangeably by mistake — ?: is about a condition, ?? is specifically about null.

💻 See the code ▾
C# 
string label = age >= 18 ? "Adult" : "Minor";   // ✅ picks by condition

Nothing to do with null — only the true/false result decides which side wins.

C# 
int? x = 0;
int y = x ?? 5;   // y is 0, not 5 — 0 isn't null

The trap in action — 0 is a real value, so ?? never reaches for the fallback.

🌍 Real-world example ▾

A fork in the road vs. a spare key. ?: is a fork in the road — you take the left path or the right path based on a sign. ?? is a spare key — you use your own key if you have one, and only reach for the spare if yours is missing.
