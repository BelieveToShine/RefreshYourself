box-sizing — the one line that decides whether your width: 100% fits or overflows

What is the CSS box model, and what's the difference between content-box and border-box?

Why it matters ▾
  • Every element's rendered size traces back to this — get it wrong and every layout question after it gets harder to reason about.
  • box-sizing: border-box shows up in nearly every real CSS reset, and interviewers use this question to check whether you actually understand what width measures.
  • "Why does my width: 100% box overflow its container" is one of the most common early CSS debugging questions asked in interviews.
🔥 Easy interview recall

content-box → width = content only

border-box → width = content + padding + border

Think: content-box adds padding/border on top of your width. border-box squeezes them inside it instead.

🧠 Visual Mental Model — understand it in 5 seconds
⚠️ Common Trap

width doesn't mean "total width" by default. With the default content-box, width sets only the content's size — padding and border are added on top, so the rendered box is always bigger than the number you wrote unless box-sizing: border-box is set.

🔄 Likely Follow-up

Why do most CSS resets set box-sizing: border-box on everything? So width/height mean the actual rendered size, padding and border already included — that's exactly why a width: 100% box then stays inside its parent instead of overflowing it.

🎯 Say this in the interview — the exact lines to land

"Every element is four nested boxes — content, padding, border, and margin. By default (content-box), width/height size only the content, so padding and border add extra size on top. box-sizing: border-box makes width/height include padding and border instead, which is why most CSS resets turn it on globally — it stops padding from silently growing an element past its intended size."

  • content-box (default) → width = content only; padding/border add on top.
  • border-box → width = content + padding + border, already included.
  • width: 100% overflow → happens under content-box when padding/border push the real rendered width past the parent.
  • Four layers, always the same order: content → padding → border → margin.
  • Margin is space outside the border — it isn't part of the element's own rendered box at all.
📖 Explanation ▾

Every element on a page is really four nested boxes: content (the text/image itself), padding (space between the content and the border), border (the line drawn around the padding), and margin (space outside the border, pushing other elements away). This nesting is exactly what the browser's Layout stage computes for every single element — see the fuller rendering-pipeline picture for where Layout sits relative to Style, Paint, and Composite.

box-sizing decides what width/height actually measure. The default, content-box, sizes only the content — padding and border then get added on top, so the box you see rendered is always bigger than the number you wrote. border-box flips that: width/height now describe the total rendered size, and the browser shrinks the content area to make padding and border fit inside that number instead of adding to it. That's the practical reason almost every real CSS reset sets box-sizing: border-box globally — it makes sizing predictable, and it's why a width: 100% child stops overflowing its parent the moment padding or border gets added.

💻 See the code ▾
CSS 
.box {
  width: 300px;      /* content-box is the default */
  padding: 20px;
  border: 5px solid;
}                       /* renders 360px wide, not 300px */

Padding (20px × 2) and border (5px × 2) add 60px on top of the 300px content — the box renders at 360px.

CSS 
.box {
  box-sizing: border-box;  /* width now includes padding + border */
  width: 300px;
  padding: 20px;
  border: 5px solid;
}                          /* still renders exactly 300px wide */

Same padding and border — but the content area shrinks to fit inside 300px, so the total stays 300px.

🌍 Real-world example ▾

Think of a framed photo on a wall. The photo itself is the content; the mat board around it is the padding; the wooden frame is the border; the gap of wall you leave before the next picture is the margin. If you buy a frame sized to fit "the photo" (content-box thinking), the mat and wood still add extra size once you hang it. If you instead buy a frame sized to fit "the whole finished piece" (border-box thinking), the photo inside just gets smaller to match — the frame on the wall is the size you actually asked for.
