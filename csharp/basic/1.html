Value or Reference? What's really being copied

Why it matters ▾
  • Explains the "why did that change on its own?!" bug before it bites you.
  • Tells you when it's actually safe to copy or share data.
  • Near-guaranteed first question in a C# interview.
🔥 Easy interview recall

Value type → own copy

Reference type → shared object

Think: int, bool, struct → copy class, array, string → shared

🧠 Visual Mental Model — understand it in 5 seconds
⚠️ Common Trap

string is not a value type. It's a reference type that just never lets you mutate it — that's why it feels like a copy.

🎯 Say this in the interview — the exact lines to land

"Value types copy the data, so each variable is independent. Reference types copy the address, so multiple variables can share — and mutate — the same object."

  • Stack holds values. Heap holds shared objects.
  • int / bool / double / struct → valueclass / array / string → reference
  • Two variables, one object — change it through either, both see it.
📖 Explanation ▾

Value types hand you a fresh copy every time — int, bool, any struct. Touch the copy, the original never feels it.

Reference types hand you a set of directions to the same house — class, arrays, string under the hood. Two variables, two addresses, one house. Redecorate through either door and it shows for both.

One question fixes almost every "why did that change on its own?" bug: value, or reference?

Value typeReference type
What gets copiedThe actual dataThe address (a pointer)
Assign to a new variableIndependent copySame object, two names
Change through the copy❌ Original untouched✅ Original changes too
Common examplesint, bool, structclass, array, string
💻 See the code ▾
C# 
int x = 5;
int y = x;   // copy — a new, separate 5
y = 10;        // ✅ x is still 5

Changing y never touches x — each variable owns its own copy.

C# 
Person p1 = new Person { Name = "Sam" };
Person p2 = p1;       // same object, not a copy
p2.Name = "Alex";   // ⚠️ p1.Name is "Alex" too

p1 and p2 point to the same object — there's only one Person to change.

🌍 Real-world example ▾

Photocopy vs. shared doc. Hand someone a photocopy (value) and they can scribble on it all day — your original is untouched. Share a Google Doc link (reference) instead, and their edit is instantly your edit too — same document, two doors in.
