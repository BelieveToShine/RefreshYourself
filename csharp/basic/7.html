🔥 C# · Basic · Hot

A fixed shelf, or a box that grows?

Why it matters ▾
  • Explains the "collection was of a fixed size" exception before it surprises you.
  • Tells you which one to reach for when you don't know the count up front.
  • A quick, common warm-up question before generics get discussed properly.
🔥 Easy interview recall

Array → fixed shelf, locked forever

List<T> → swaps itself for a bigger one

Think: List<T> is an array wrapped with auto-resize

🧠 Visual Mental Model — understand it in 5 seconds
⚠️ Common Trap

Reading past the end doesn't return null — it throws. arr[4] on a 4-slot array is an IndexOutOfRangeException, not a quiet null.

🎯 Say this in the interview — the exact lines to land

"Array size is fixed at creation, with no .Add(). List<T> is an array wrapper that swaps itself for a bigger array automatically when it runs out of room."

  • List capacity usually doubles, so growth is occasional, not constant.
  • Know the exact size and it won't change? Array is still leaner.
📖 Explanation ▾

An array's length is locked in the moment it's created — there's no .Add(), because there's nowhere for a new item to physically go. Want more room? You have to create a whole new, bigger array.

List<T> looks like it grows freely, but under the hood it's doing exactly that "make a bigger array" step for you automatically, whenever it runs out of room — usually by doubling its internal capacity, so it doesn't have to resize on every single Add().

Arrays are still faster and lighter when you truly know the size up front and it never changes — List<T> is the everyday default when it might.

💻 See the code ▾
C# 
int[] arr = new int[3];   // fixed size, can't grow
arr[0] = 10;       // ✅ fine
arr[5] = 1;        // ❌ throws IndexOutOfRangeException

The array never grows to fit — going past slot 2 is always out of bounds.

C# 
List<int> list = new List<int>();
list.Add(10);
list.Add(20);   // ✅ just works, however many times

No size to plan for — List<T> resizes itself behind the scenes.

🌍 Real-world example ▾

A fixed bookshelf vs. a storage unit you can upgrade. An array is a shelf built with exactly 4 slots — you can't wedge in a 5th book, you'd need to build a new shelf. List<T> is a storage unit that automatically swaps itself for a bigger one the moment you run out of space, and hands you the same key either way.
