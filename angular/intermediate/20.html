View encapsulation — styles stay scoped to their component, by default

How do component styles stay scoped in Angular, and what do :host and ::ng-deep do?

Why it matters ▾
🎨 Component styles
❗ ProblemIn plain CSS every rule is global, so a .title style written for one component can silently restyle another component with the same class name.
✅ SolutionAngular scopes a component's styles to that component by default (Emulated encapsulation). :host styles the component's own tag, and ::ng-deep is the discouraged escape hatch to reach inside children.
RecallScoped by default. :host = my own tag. Avoid ::ng-deep.
🔥 Easy interview recall

Component styles are "private by default." :host = the component's own tag.

Think: Emulated = Angular adds an attribute to your elements and to your CSS so they only match each other.

🧠 Visual Mental Model — understand it in 5 seconds
⚠️ Common Trap

Reaching for ::ng-deep to restyle a child component is a trap. It punches a hole through the scoping, so the style can leak to other places, and Angular's docs mark it as deprecated (it still works for now). Prefer a CSS custom property the child exposes, a global stylesheet for truly shared styles, or :host ::ng-deep at the very least so it stays limited to this component.

🔄 Likely Follow-up

"When would you pick ViewEncapsulation.None or ShadowDom?" None turns scoping off, so the component's styles become global — rare, for things like a theme or third-party markup. ShadowDom uses the browser's native shadow DOM for real isolation, but outside styles then cannot reach in at all.

🎯 Say this in the interview — the exact lines to land

"By default Angular uses Emulated view encapsulation: it adds a generated attribute to each component's elements and rewrites its CSS to require that attribute, so styles stay scoped to the component. :host targets the component's own tag, and I avoid ::ng-deep because it breaks that scoping."

  • ViewEncapsulation.Emulated is the default — scoping done with generated attributes.
  • ShadowDom uses the browser's real shadow DOM; None makes the styles global.
  • :host styles the component's own element — :host(.active) only when it has that class.
  • A parent's styles do not reach into a child's template in Emulated mode.
  • ::ng-deep pierces the scoping and is discouraged — use CSS custom properties instead.
📖 Explanation ▾

Plain CSS has no scoping: any rule can hit any element on the page. Angular fixes that with view encapsulation. In the default mode, Emulated, Angular adds a generated attribute (something like _ngcontent-xyz-c1) to every element in a component's template, and rewrites that component's CSS so each selector also needs the attribute. The result: a rule in component A can only match A's own elements. Nothing special happens in the browser — it is just attributes and selectors.

You can change the mode with encapsulation in @Component. ShadowDom uses the browser's native shadow DOM, which is real isolation. None turns scoping off, so the styles are global. The component's own tag (the host element) is not inside its template, so you style it with :host — for example :host { display: block; } or :host(.active) { ... }.

Because of the scoping, a parent cannot style the inside of a child. ::ng-deep removes the scoping for the part of the selector after it, so it can leak into other components. It is discouraged (the docs mark it deprecated, though it still works). Cleaner choices: let the child expose CSS custom properties (--card-bg), use a global stylesheet for shared looks, or keep the escape local with :host ::ng-deep if you truly must.

💻 See the code ▾
CSS 
/* card.component.css — scoped to this component only */
:host { display: block; border: 1px solid #ccc; }       /* the <app-card> tag itself */
:host(.active) { border-color: royalblue; }              /* only when it has class="active" */
.title { color: var(--card-title-color, black); }        /* ✅ child exposes a custom property */

:host styles the component's own tag; a custom property lets the parent theme it without piercing the scoping.

TypeScript 
@Component({
  selector: 'app-card',
  template: `<h2 class="title"><ng-content></ng-content></h2>`,
  styleUrl: './card.component.css',
  encapsulation: ViewEncapsulation.Emulated,   // default — shown here for clarity
})
export class CardComponent {}

Swap Emulated for ViewEncapsulation.ShadowDom or None to change the mode.

🌍 Real-world example ▾

Every apartment has its own door key. What you do inside your flat (paint, music) stays inside it, and neighbours cannot change it — :host is decorating your own front door, and ::ng-deep is a master key that opens every flat, which is why building managers avoid handing it out.
